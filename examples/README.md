# 언어별 예제 안내

실제 코드는 각 언어 디렉터리 안에서 관리합니다. 이 디렉터리는 언어별 예제와 공통 정적 배치를 연결합니다.

| 언어 | 예제 | 제공 범위 |
| --- | --- | --- |
| Go | [시작 템플릿](../go/examples/starter/main.go), [토큰 소비](../go/examples/tokens/main.go) | 동작하는 Go 스타일 API·실행형 견본 |
| Python | [토큰 소비](../python/examples/read_tokens.py) | 데이터 소비 예제. UI 패키지 미구현 |
| JavaScript | [토큰 소비](../javascript/examples/read-tokens.mjs) | 데이터 소비 예제. UI 패키지 미구현 |
| Shell | [ANSI 견본](../shell/examples/terminal-colors.sh) | 참조 출력. 스타일 함수 패키지 미구현 |

[공통 컴포넌트 정적 배치](components.txt)는 언어와 무관한 참고 예시입니다.
