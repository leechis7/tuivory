# Tuivory JavaScript

**한국어 (기본)** · [English](README.en.md)

현재는 [공통 디자인 데이터](../design/README.md)를 읽는 Node.js 예제만 제공합니다. JavaScript TUI 스타일 패키지, 프레임워크 어댑터, npm 배포는 아직 구현하지 않았습니다. Go에 의존하지 않습니다.

```sh
node javascript/examples/read-tokens.mjs dark 256
```

예제는 외부 패키지 없이 `design/tokens/candidate.json`을 읽습니다. Node.js 18 이상을 사용합니다. 향후 패키지 API와 배포 방식은 별도 작업에서 정합니다.
