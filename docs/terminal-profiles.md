# 단말 능력과 테마

**한국어 (기본)** · [English](terminal-profiles.en.md)

사용자 테마와 표현 능력은 독립된 입력입니다. 기본 비교 축은 다크·라이트·흑백 × 8색·16색·256색·True Color의 12조합입니다.

| 프로필 | 참조 표현 | 주의할 점 |
| --- | --- | --- |
| ANSI8 | 인덱스 0~7 | 밝은색 번호로 중요 정보를 구분하지 않기 |
| ANSI16 | 인덱스 0~15 | 기본색+Bold가 밝은 전경색으로 바뀌는 모델도 확인 |
| Indexed256 | 인덱스 0~255 | 기본 16색은 사용자 팔레트 영향을 받을 수 있음 |
| True Color | RGB 또는 명시적 인덱스 | RGB 지원 판단과 실제 전송 경로를 기록 |

참조 검사기는 기본 16색에 tcell의 명목 RGB를 사용하고, 16~231의 색 큐브와 232~255 회색 단계로 인덱스를 계산합니다. 실제 에뮬레이터의 기본 16색은 다를 수 있으므로 검사 결과를 실측으로 표현하지 않습니다.

굵기 모델은 ‘글꼴 굵기만 변경’과 ‘ANSI 전경색 0~7을 8~15로 변경’ 두 가지를 비교합니다. 모든 단말이 둘 중 하나로 정확히 동작한다고 단정하지 않습니다. 반전·Dim·밑줄·문자 폭도 개별 기능으로 기록해야 합니다.

TERM 이름만으로 색상·마우스·확장 키 지원을 모두 추정하지 않습니다. 라이브러리가 보고한 능력, 실제 터미널/버전, SSH·tmux 등 연결 경로, 팔레트·굵기 설정을 [증거 양식](../evidence/README.md)에 남깁니다.

특정 GUI 프로그램의 F키 배치나 DB 작업의 위험 확인 정책은 제품별 계약으로 둡니다. 이 가이드는 단말 입력 프로토콜을 새로 정의하지 않습니다.
