## 0.11.0 그리드 상태 규칙

[그리드 데이터 작업](grid-workspace.md)은 편집/승인 대기/오류 표면, 항상 남는 변경 셀 `*`와 독립 행 표식을 정의합니다. 선택·포커스로 변경 여부를 지우지 않습니다. 행의 Edited는 다른 셀을 변경색으로 칠하지 않습니다. 고정/일반 열 영역은 겹치지 않고 좁은 단말에서 자르며 표시/순서/보기 상태는 안정 ID를 사용합니다. 권한·NULL 값·승인/트랜잭션·전체 검색·파일 저장은 호스트 책임입니다. 모든 테마/색상 수와 Unicode/ASCII는 기존 의미 역할을 사용합니다. [공통 컨트롤 규칙](../design/controls.md).

## 그리드 실제 커서 (0.11.1)

편집 버퍼에 가짜 커서 문자를 넣지 않습니다. 텍스트·마우스·로컬 커서가 같은 grapheme 뷰포트를 사용합니다. 포커스 뷰는 위치·가시성만 소유하며 NULL·승인 대기·클리핑·무효화·포커스 해제 때 오래된 커서를 숨깁니다. Go는 NewGridView와 NewCursorScreen/PreserveCursorTty로 backend 기본 모양·깜빡임 명령을 제거합니다. Rust는 GridWidget::render_frame을 사용하고 버퍼 전용 Widget은 실제 커서를 등록하지 않습니다. 전역 포커스·레이어 선택은 앱 책임입니다. [연결·근거](grid-workspace.md).

[Python·TypeScript/JavaScript·C·C++·Java 독립 지원](languages.md): 미배포 독립 컴포넌트 구현 작업입니다. 구현과 런타임은 언어별로 독립적이며 기존 공개 0.11.1은 유지합니다.

드래그 미리보기는 원본 데이터·선택·펼침을 바꾸지 않습니다. 이동 표식은 실제 바탕색을 유지한 굵은 글씨·밑줄로 표시하고, 거부는 !로 구분합니다. 테마·배치·포커스 변경은 진행 중 캡처를 취소하며, 확정 이동은 앱 승인을 거칩니다.

그리드 드래그 캡처는 컴포넌트 내부에 한정합니다. 셀과 행 번호로 범위를 선택하고, 헤더 구분선은 열 너비를, 제목은 같은 고정 영역 안에서 열 순서를 바꿉니다. 움직이지 않은 헤더는 놓을 때 정렬을 한 번 요청합니다. 영역 밖 놓기는 앱이 전달하고 입력 대상이 바뀌면 캡처를 취소합니다. [독립 그리드 API](language-grid.md).

대화상자 버튼은 내용 영역에서 줄바꿈하고 각 행을 독립적으로 가운데 정렬합니다. 버튼이 하나만 남은 행에도 같은 규칙을 적용합니다. 그리기와 포인터 판정에는 같은 사각형을 사용합니다. [확인창 동작](modals.md)

그리드 헤더는 구분선과 빈칸까지 행 전체에 `grid.header`를 적용합니다. 다크 테마는 청회색, 라이트 테마는 옅은 청색, 흑백은 반전으로 구분합니다. 다크·라이트의 8색에서는 파랑, 16색에서는 청록을 사용합니다. 본문 행의 선택·편집 스타일은 그대로 사용합니다.

현재 데이터 셀은 밑줄 없이 `grid.active` 배경으로 표시합니다. 8색은 헤더와 같은 색을 사용하며 다크·라이트는 파랑, 흑백은 밝은 회색입니다. 그 외 색상 모드는 별도의 명도를 사용합니다. 다크·라이트 8색의 범위 선택은 청록으로 표시해 파란 현재 셀과 구분합니다. 수정된 현재 셀에는 별표를 남기고, 다른 수정 셀은 기존 수정 배경색을 유지합니다.

탭 윤곽은 단일선을 사용합니다. 활성 탭은 선택 바탕색으로 표시하고, 아래 구분선을 그릴 공간이 있으면 내용 영역 쪽을 엽니다. 키보드 포커스는 따로 표시하고 비활성 탭은 흐리게 표시합니다. [탭 배치](workspace.md#탭)에서 한 줄·ASCII 표현도 확인할 수 있습니다.
