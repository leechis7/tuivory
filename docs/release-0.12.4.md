# Tuivory 0.12.4 릴리스

**한국어 (기본)** · [English](release-0.12.4.en.md)

공통 그리드가 안정 행 ID를 기준으로 추가·수정·삭제 예정 표식을 표시합니다. 삭제 예정 셀을 선택적으로 흐리게 표시합니다. [그리드 사용법](grid.md)

| 언어 | 설치·실행 |
| --- | --- |
| Go | `go get github.com/leechis7/tuivory/go@v0.12.4` |
| Rust | Cargo Git 의존성에 `rust/v0.12.4` 태그를 지정하거나 `.crate` 소스를 사용합니다. |
| Python | 다운로드한 휠을 `python -m pip install ./tuivory-0.12.4-py3-none-any.whl`로 설치합니다. |
| TypeScript/JavaScript | 다운로드한 패키지를 `npm install ./tuivory-0.12.4.tgz`로 설치합니다. |
| C·C++ | 호스트 아키텍처에 맞는 SDK를 풀고 헤더와 정적 라이브러리(C)를 사용합니다. |
| Java | JDK/JVM 17 이상에서 JAR을 클래스패스에 추가하거나 `java -jar tuivory-0.12.4.jar --demo grid`로 예제를 실행합니다. |

[설치 안내](installation.md) · [검증 기록](evidence/tvr34-grid-row-drafts-results.json)

Go·Rust·C·C++의 ARM64 및 x86_64 정적 예제와 Python·TypeScript/JavaScript·Java 패키지는 GitHub에서 받을 수 있습니다. 다운로드한 파일은 `sha256sum -c SHA256SUMS`로 확인합니다. [릴리스 다운로드](https://github.com/leechis7/tuivory/releases/tag/go/v0.12.4)
