# Tuivory 0.12.4 release

[한국어 (기본)](release-0.12.4.md) · **English**

Grids show pending additions, modifications and deletions by stable row ID, with optional deletion dimming. [Grid guide](grid.en.md)

| Language | Installation or execution |
| --- | --- |
| Go | `go get github.com/leechis7/tuivory/go@v0.12.4` |
| Rust | Use Git tag `rust/v0.12.4` in the Cargo dependency or use the `.crate` source archive. |
| Python | Install the downloaded wheel with `python -m pip install ./tuivory-0.12.4-py3-none-any.whl`. |
| TypeScript/JavaScript | Install the downloaded archive with `npm install ./tuivory-0.12.4.tgz`. |
| C and C++ | Extract the SDK for your architecture and use its headers and C static library. |
| Java | Add the JAR to your classpath with JDK/JVM 17 or later, or run `java -jar tuivory-0.12.4.jar --demo grid`. |
