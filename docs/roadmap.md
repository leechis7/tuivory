# 로드맵

**한국어 (기본)** · [English](roadmap.en.md)

## 제품 목표

앱에서 import해 사용하는 TUI 스타일 패키지를 제공합니다. Go 스타일 패키지 `v0.0.1`을 배포했으며 현재는 Go 사용성·원본 동등성을 유지하고 LazyOra의 실제 import 적용을 검증하는 데 집중합니다. 문서·명세·템플릿은 패키지의 사용과 검증을 지원하며, 다른 언어의 스타일 패키지는 후속 확장입니다. Bootstrap·Tailwind CSS·MUI처럼 공통 규칙과 재사용 구현, 카탈로그를 갖추는 방향이며 웹 CSS를 터미널에 그대로 적용하지 않습니다.

현재는 Go 패키지의 원본 동등성을 유지하면서 TVR-5에서 LazyBeaver를 위한 Rust 기반을 진행합니다. Rust 공통 토큰·스타일 코어, 선택적 Ratatui 어댑터와 한·영 대화형 예제를 로컬 구현·검증했습니다. 실제 LazyBeaver 적용과 배포는 남아 있습니다. TVR-7의 공통 UI 개선은 별도 에픽으로 관리합니다.

루트는 언어 중립적인 `design/docs/go/rust/python/javascript/shell/examples` 구조를 사용합니다. Go API는 `github.com/leechis7/tuivory/go` 하위 모듈로 분리하며 첫 배포 버전은 0.0.1입니다.

## 현재 구현

- [공통 명세](../design/README.md): 의미별 역할, 단말 프로필, 컴포넌트 상태·조작·셀 배치 계약.
- [공통 토큰](../design/tokens/README.md): JSON 데이터·스키마 초안, 12팔레트·192쌍 참조 후보.
- [Go 패키지](lazyora-extraction.md): LazyOra 실제 테마·프로필·상태 스타일과 stock tview 적용 함수, 시작 템플릿. 프레임워크 독립 후보 토큰 로더도 제공합니다.
- [Go 견본](playground.md): tview 화면에서 입력·선택·표·팝업과 테마 변경 상태 보존 검사.
- [Rust 코어](../rust/README.md): 공통 후보 토큰 검증·프레임워크 독립 색상/스타일·독립 Cargo 패키지·JSON 예제·선택적 Ratatui 어댑터·[대화형 예제](rust-playground.md). 아직 미배포입니다.
- Python·Node.js의 공통 데이터 읽기 예제 및 Go와의 동등성 검사.
- 팔레트 참조 계산, 로컬 링크 검사, 실제 단말 검증 양식.

Go 패키지는 `v0.0.1`로 배포했습니다. 여러 언어의 완성 위젯 SDK나 Python·JavaScript·Shell UI 패키지를 제공한다는 뜻은 아닙니다. 견본의 한국어·영어 선택과 영문 참조 이미지는 `main`에 병합했으며 새 버전 태그는 아직 없습니다.

## 다음 단계

1. LazyOra에서 Go 스타일 어댑터를 사용해 공통 API와 앱 경계를 검증합니다.
2. 로컬 구현한 Rust 코어·Ratatui 어댑터·DB 없는 예제의 실제 LazyBeaver 적용 경계와 배포를 검증합니다. 공통 트리·탭·패널 등은 TVR-7의 점검·명세 순서에 맞춥니다.
3. Python·JavaScript 중 한 프레임워크에서 입력·버튼·목록·모달을 구현해 같은 명세의 재사용성을 검증합니다.
4. Shell의 ANSI 출력 템플릿을 정리하고, 검증한 동작을 언어별 재사용 컴포넌트로 추출하고 간격·테두리·상태 토큰을 확장합니다.
5. 카탈로그에서 언어별 예제·지원 범위·검증 근거를 함께 탐색하도록 확장합니다.
6. 실제 단말 관찰을 수집하고 패키지 이름·배포·호환성 정책을 정합니다.

참조 계산·시뮬레이션·실제 SecureCRT/MobaXterm/xterm 호환 단말 결과는 분리합니다. 입력 I/O·단말 능력 감지·DB 드라이버는 공통 코어에 넣지 않습니다. 적용 사례는 출처 링크로 연결합니다.

후속 단계는 별도 일감으로 진행합니다. 제품 major와 정식 버전은 사용자가 결정하며 커밋·GitHub 게시는 명시적 승인 후 수행합니다.
