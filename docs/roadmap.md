# 로드맵

**한국어 (기본)** · [English](roadmap.en.md)

## 제품 목표와 경계

Tuivory는 앱이 import하는 **TUI 컴포넌트 라이브러리**입니다. Go/tview·Rust/Ratatui에서 공통 컨트롤·스타일·내부 조작과 설정 가능한 배치 도구를 제공합니다. 앱은 화면 조합·전역 포커스·명령/키·내용·데이터·업무 동작을 결정합니다. 앱에 UI 조합 코드가 있다는 이유로 공통 라이브러리 이전을 요구하지 않습니다. [책임 범위](component-boundary.md).

루트는 언어 중립이며 공통 명세·토큰은 design/, 구현·패키지는 각 언어 디렉터리에 둡니다. 예제는 사용법을 보여주는 호스트이며 필수 화면 템플릿이 아닙니다. 제품 major와 릴리스는 사용자가 결정합니다.

## 현재 제공 범위

- **배포 v0.2.0**: Go `go/v0.2.0`, Rust `rust/v0.2.0`. 공통 상태/포커스·폼·평면 목록/검색·트리·탭·패널/분할·경로/상태줄·기본 Grid·알림/진행·배치/Help API와 한영 예제. [지원 점검표](component-audit.md) · [릴리스](release-0.2.0.md).
- **TVR-17 로컬 커밋 `e34b824`**: 같은 Grid의 옵션/프리셋·범위·열 구성·상태줄·지연 응답 보호. GitHub와 버전 태그에는 미게시입니다. [그리드](grid.md).
- **TVR-7 책임 범위 정정 후속**: 문서·점검표와 호스트가 배치/포커스 순서/종료 키를 선택하는 예제 보완. 로컬 커밋에 포함하며 GitHub에는 미게시 작업입니다. [예제와 경계](component-boundary.md).
- **Python·JavaScript·Shell**: 현재 토큰 읽기·참조 출력 예제입니다. 완성 UI 패키지 지원으로 기록하지 않습니다.

## 다음 순서

1. 책임 범위·지원 점검표를 기준으로 실제 적용 앱이 공통 컴포넌트를 연결하도록 지원합니다. 기존 Go 추출 스타일과 후보 팔레트 차이도 구분합니다.
2. TVR-17의 승인된 게시·릴리스 후 실제 LazyOra 적용을 검증합니다. 라이브러리 구현·로컬 검사·게시·실제 앱 통합은 각각 기록합니다.
3. 중첩 메뉴는 확인된 미제공 기능이므로 실제 요구를 확인한 뒤 별도 TVR 일감으로 구체화할 후보입니다. 이미 구현한 탭 넘침·단축키 도움말을 중복 개발하지 않습니다.
4. [TVR-15 Python](https://leechis7.atlassian.net/browse/TVR-15), [TVR-16 TypeScript·JavaScript](https://leechis7.atlassian.net/browse/TVR-16)를 일반 런타임 기반 패키지로 확장합니다. 사용자 지정에 따라 정적 링크·독립 실행파일·CentOS 검증은 필수 조건에서 제외합니다.
5. Go·Rust의 실제 LazyOra/LazyBeaver 적용과 고객 단말 결과를 수집합니다. SQL·세션·저장·업무 흐름을 공통 코어에 넣지 않습니다.

공통 UI 에픽 TVR-7과 언어별 기반 에픽 TVR-5/6은 열린 상태로 유지합니다. 커밋·GitHub 게시는 해당 변경의 명시적 승인 후 진행하며 단계 통합은 dev까지만, main·태그·Release는 별도 릴리스 지시를 따릅니다. 원격 CI·물리 단말/SSH·앱 통합 결과를 로컬 테스트와 합쳐 기록하지 않습니다.
