# Tuivory Python

**한국어 (기본)** · [English](README.en.md)

현재는 [공통 디자인 데이터](../design/README.md)를 읽는 표준 라이브러리 예제만 제공합니다. Python TUI 스타일 패키지, 위젯 어댑터, PyPI 배포는 아직 구현하지 않았습니다. Go 코드를 호출하지 않습니다.

```sh
python3 python/examples/read_tokens.py dark 256
```

모든 명령은 저장소 루트 기준입니다. 예제는 `design/tokens/candidate.json`을 읽습니다. 향후 패키지 API와 배포 방식은 별도 작업에서 정합니다.
