# Tuivory Python

[한국어 (default)](README.md) · **English**

Only a standard-library example reading [shared design data](../design/README.en.md) is available. A Python TUI style package, widget adapters, and PyPI distribution are not implemented. It does not call Go.

```sh
python3 python/examples/read_tokens.py dark 256
```

Run from the repository root. The example reads `design/tokens/candidate.json`. Future package APIs and distribution are separate work.
