# 포커스 영역 테두리 검증

**한국어 (기본)** · [English](focus-borders.en.md)

이 문서는 해당 단계의 과거 검증입니다. 이후 배경·비활성 표시 변경은 [후속 검증](background-fix.md)을 참고하세요.


TVR-7의 0.3.0 이후 미배포 변경입니다. Go tview 카드·일반 팝업은 원래 포커스 이중선을 사용하므로 앞서 단일선이라고 설명한 부분을 정정합니다. 탐색·토큰·도움말의 포커스 색상을 보완하고 현재 조작 영역 이중선·비활성 단일선·메뉴 단일선 규칙을 문서화/검증합니다. 테두리가 없는 개별 컨트롤에는 테두리를 추가하지 않습니다. Rust 공통 패널은 이미 같은 규칙을 지원합니다.

12개 팔레트에서 Go 입력/버튼/목록/그리드/탐색/토큰/도움말 7개 영역과 도움말/미리보기/편집 팝업을 검사합니다. Show 이후 실제 Runes/Bytes의 네 모서리·가로/세로 선, 테두리 색상·호출 위치 복귀·테마/리사이즈를 확인합니다. 기존 두 칸 문자 팝업 회귀도 유지합니다. Rust TestBackend로 활성/비활성 Unicode·ASCII 공통 패널과 메뉴 예외를 확인합니다. 탐색/그리드/편집 장면을 포함한 한영 Go 견본 참조 화면 14개를 현행화합니다.

[결과와 정확한 해시](focus-borders-results.json) · [사용법](../docs/playground.md) · [메뉴 후속 검증](menu-single-border.md).

커밋·게시·원격 CI·릴리스·CentOS 검증은 수행하지 않습니다. 기존 0.3.0 태그/자산은 유지합니다.

추가로 실제 PTY에서 창 축소/복원 시 Go 견본의 교착을 재현했습니다. Application 그리기 잠금 안의 reflow → Pages.HidePage → SetFocus 재진입이 원인이며, 페이지/포커스 변경을 UI 갱신 큐로 옮겼습니다. 간이 판독기와 별도로 임시 검증 환경의 pyte VT 판독기로 실제 테두리·리사이즈/복귀를 확인합니다. 제품 의존성은 추가하지 않았습니다. `smoke_playground.py --resize`를 영구 회귀로 남기며 CI에 연결합니다. 원격 CI 실행은 아직 하지 않았습니다.
