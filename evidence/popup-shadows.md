# TVR-19 팝업 그림자 검증

**한국어 (기본)** · [English](popup-shadows.en.md)

기준 커밋 `6c67262` 이후 `codex/TVR-19-popup-shadow`의 미커밋 소스입니다. TVR-20은 사용자 지시로 커밋했으며, TVR-19의 커밋·원격 게시·CI·릴리스는 수행하지 않았습니다. 공개 0.4.0에는 이 기능이 없습니다.

Go `ShadowView`, Rust `ShadowWidget`·`MenuPopupWidget::shadow`, 공통 위치 계산을 추가했습니다. 그림자는 기본 끄기이며 Auto·Solid·Dim을 선택합니다. 카드만 입력 대상으로 사용합니다. 기존 `PopupShadowStyle`·`DimRegion`은 새 Go 래퍼에서도 사용하며 Deprecated 대상으로 추가하지 않았습니다.

- 공통 32개 위치 데이터: 기본/모서리/작은 영역/빈 영역/오프셋 viewport/큰 요청/사용자 오프셋과 정수 극값.
- 다크·라이트·흑백 × 8/16/256/True Color × 네 모드 × 한글/CJK/이모지/결합 문자. Go Show 이후 실제 출력과 Rust 버퍼에서 본문에 Dim이 번지지 않는지, 양쪽 경계·바깥 스타일·호스트 배경 복원을 확인했습니다. Rust 일반 위젯 경계와 Go 그림자 클릭/포커스 차단도 검사했습니다.
- Go 전체 race/vet·Python 검사·공통 데이터/API/문서 링크 검사, Rust 1.85.1 코어 및 1.88.0 전체 기능/타깃/doctest/fmt/Clippy. 외부 Go 모듈과 Rust 패키지에서 네 모드의 공개 API를 import·실행했습니다.
- Go/Rust × 한영 × 네 모드의 16개 PTY에서 메뉴 탐색·원래 패널 복귀·붙여넣기 차단·마우스·테마/색상/문자 변경·리사이즈·종료/단말 복원을 확인했습니다. 켠 모드에서는 F6 네 번으로 모든 모드를 순회합니다. Auto 초기 사례는 ASCII로 시작합니다.
- 실제 Rust 위젯에서 12개 한영 SVG(각 12팔레트)를 생성했습니다. 기본 끄기의 기존 메뉴 SVG 10개는 바이트 단위로 동일합니다.
- 기본 `make build`의 Linux ARM64 Go 산출물은 동적 로더·DT_NEEDED 없는 정적 ELF입니다. Rust 신규 필수 의존성은 없습니다. CentOS 검증은 수행하지 않았습니다.

Dim은 터미널 전경 속성입니다. 이미지의 Dim 밝기는 SVG 렌더러의 근사이며 실제 단말과 같다고 보장하지 않습니다. 빈 배경은 어두워지지 않고 단말에서 속성을 무시할 수 있습니다. 검정 Solid도 검정 배경에서는 구분되지 않을 수 있으므로 Auto는 패턴으로 보완합니다. 위치·닫기·배경 다시 그리기는 앱 책임입니다.

[사용법·화면](../docs/popup-shadows.md) · [구조화 결과](popup-shadow-results.json). 로컬 상세 로그는 `bin/validation/TVR-19/`에 두며 배포 파일에 포함하지 않습니다.

후속 조정: 사용자 피드백으로 기본 그림자를 오른쪽 2칸에서 **1칸**으로 줄이고 아래 1행은 유지했습니다. 공유 위치 데이터·Go 그림자 race·Rust 팝업 그림자 5개 테스트와 한영 이미지 생성, Go 한글/Rust 영어 Dim PTY를 다시 검증했습니다. 위 전체 검사·16개 PTY 기록은 이 폭 조정 이전 결과입니다.

최종 조정: 셀 비율을 고려해 기본 오프셋을 **오른쪽 2칸·아래 1행으로 복원**하고 Auto의 RGB 밝기를 표면의 60%에서 80%로 높여 명암을 약하게 했습니다. 256색은 해당 밝기 근처의 회색으로 양자화합니다. 8/16색·검정 표면 패턴 대체는 유지합니다. 이 변경 후 공유 위치 32개, Go 그림자 race/Show 출력과 Rust 팝업 그림자 5개 테스트, 한영 이미지 생성·링크/데이터 일치를 다시 확인했습니다. 위 1칸 조정은 중간 이력입니다.
