# Tuivory Shell

[한국어 (default)](README.md) · **English**

Only a POSIX shell ANSI color sample for observing [terminal profiles](../docs/terminal-profiles.en.md) is available. A reusable Shell function package applying shared tokens is not implemented. No Go or Python runtime is needed.

```sh
sh shell/examples/terminal-colors.sh
```

The example prints ANSI samples without changing terminal settings or the user palette. Shared-data interpretation and UI templates remain future work.
