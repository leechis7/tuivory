# 이동 요청과 드래그 규칙

**한국어 (기본)** · [English](drag.en.md)

0.10.0 TVR-18 규격입니다. [사용법·공개 API 연결·예제·화면](../docs/drag-drop.md), [공통 판정 사례](drag-cases.json).

| 단계 | 데이터/선택/포커스 | 캡처·피드백 |
| --- | --- | --- |
| down/armed | 변경하지 않음 | 이동 가능한 원본 ID, 모델/상태/영역 버전 고정 |
| move/dragging | 변경하지 않음 | 기본 최대 축 거리 2셀, 대상·앞/뒤/자식 위치와 허용 여부 계산 |
| up/drop | 변경하지 않음 | 현재 데이터·정책을 재검사하고 요청 1개 반환, 캡처 해제 |
| reject/cancel/stale | 변경하지 않음 | 미리 보기·캡처 제거, 요청 없음 |
| 앱 승인/적용 | 앱이 불변 모델 교체 | 안정 ID로 활성/포커스/메타데이터·하위 트리 유지 |

원시 ID나 화면 좌표를 데이터 저장 명령으로 사용하지 않습니다. 요청은 프로세스 내 현재 모델에 대한 값이며 OS/외부 앱/파일/DB 이동을 실행하지 않습니다. 모델 버전은 UTF-8 바이트 길이 접두사와 FNV-1a 64비트로 계산하며 Go/Rust가 같은 데이터에서 같은 값을 사용합니다. 앱 정책은 요청 시와 최종 승인 시 다시 검사합니다.

직접 조작은 영역 내부 셀 좌표이며 캡처 중 밖의 move/up를 계속 받습니다. 모델·원래 상태·영역·테마 변경 시 취소합니다. 프레임을 생략하는 숨김 컴포넌트와 캡처 상실은 호스트가 취소합니다. 미리 보기 스크롤·펼침은 실제 상태와 별도이며 기본 끄기, 경계 move당 1항목·허용 branch 즉시 펼침을 선택할 수 있습니다. 타이머나 전역 키를 소유하지 않습니다.

흑백과 8색에서도 위치 표식과 굵기·밑줄로 허용/거부를 구분합니다. info/error 전경은 실제 surface 배경에서 본문 대비 규칙을 적용합니다. Unicode `│ ↑ ↓ ↳`와 ASCII `| ^ v +`, 거부 `!`를 제공하며 일반 비활성 표식을 추가하지 않습니다. 긴 이름은 기존 셀 폭·생략 규칙을 유지하고 피드백은 예약된 표식 셀 또는 탭 끝에서 그립니다.

자동 저장·업무 권한·트랜잭션·앱 전체 포커스와 단축키는 적용 앱 책임입니다.
